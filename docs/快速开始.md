# 快速开始

## 1. 选择叙事路线

旁白讲述主要事件，画面配合呈现时，用 [旁白推文](../prompts/整理版/02_旁白推文流程.md)。人物通过动作、对白和反应推动事件时，用 [对白短剧](../prompts/整理版/03_对白短剧流程.md)。

先复制所选文件中的完整启动提示词，填写来源、范围、改编权限和输出位置，再提供素材。约500字是文案长度选项，不等于60秒；人物对白与旁白的时长要试读。

## 2. 按阶段交付

| 阶段 | 模板 | 项目产物 |
|---|---|---|
| 写故事与单集剧本 | 旁白或对白路线，二选一 | `剧本.md` |
| 提取身份、造型、空间与关键物品 | [资产与参考图](../prompts/整理版/04_角色场景道具与参考图.md) | `视觉设定.md` |
| 写设定板、参考图及关键帧提示词 | 同上，按需补充分镜中的关键帧 | `图片提示词.md` |
| 拆镜头并锁定动作起止状态 | [分镜与视频提示词](../prompts/整理版/05_分镜与视频提示词.md) | `分镜.md` |
| 编排每个生成片段的时间、动作与声音 | 同上 | `视频提示词.md` |
| 配音或程序导入，需要时再做 | [台词旁白JSON](../prompts/整理版/06_台词旁白JSON.md) | 从当前文本导出的 JSON |

只创建本次需要的文件。JSON来自当前剧本，不另维护一套剧情。真实媒体生成后再增加剪辑单、素材选择记录和成片。

## 3. 在本地助手里使用

下载或克隆本仓库，把仓库目录交给助手，复制下列指令：

```text
请阅读当前知识库 README.md、prompts/整理版/00_使用说明.md 和01_通用规则.md。
路线：对白短剧。
素材：我随后提供的故事文本。
本次范围：仅完成第一集剧本，不生成媒体。
时长：先以60秒作为工作目标，根据实际内容报告估算。
改编权限：允许精简和口语化，重要人物关系、立场和结局变化单列建议。
输出：我的项目目录/剧本.md。
后续视频默认768p，提高分辨率需我明确同意。
```

把路线、素材、时长和输出位置改成自己的需求。只在浏览器阅读时，可以直接打开各模板并复制代码块，无需安装整个工具链。

## 4. 核对后再生产

用 [交付检查](../prompts/整理版/07_交付检查.md) 核对文本、时长、参考图和连续性。实际生成前还需确认所用平台、模型版本、参数支持、素材上传顺序与费用。模板不是已提交的生成任务，也不能代替参考图和生成结果的实际验收。
