# 工具与来源

本页记录整理时确认的项目入口及功能分工。它不复制外部项目源码，也不承诺所有平台都支持相同的模型或参数。能力、安装方法与许可应以各项目当前说明为准。

## Skills 与应用

| 项目 | 类型 | 在工作流中的位置 | 来源 |
|---|---|---|---|
| drama-skills | 多技能套件 | 原著分析、改编、剧本、资产、分镜、提示词、生产和剪辑 | [维护仓库](https://github.com/zenstory-ai/drama-skills) |
| DirectorSKILL | 导演技能 | 导演风格、调度、视听方案与提示词修订 | [维护仓库](https://github.com/wuwangzhang1216/DirectorSKILL) |
| Short Drama Director Suite | 多技能套件 | 短剧编剧、资产、分镜、动作设计和投喂稿 | [维护仓库](https://github.com/lixiaoxiao9888-create/manju-laoli-skill) |
| BigBanana AI Director | 独立工作台 | 资产、关键帧和镜头生产管理 | [项目仓库](https://github.com/shuyu-labs/BigBanana-AI-Director) |
| LocalMiniDrama | 独立应用 | 本地项目管理和多类素材生产流程 | [项目仓库](https://github.com/xuanyustudio/LocalMiniDrama) |
| BeefTV | 独立工作台 | 画布、项目及素材工作流 | [项目仓库](https://github.com/glanderness/BeefTV) |

前三项提供可安装的 Skill 入口；后三项的主要交付是应用或工作台，不能把整个应用目录当作 Skill 安装。无需为了使用本知识库把六个项目全部装上。

## 记录边界

整理时，drama-skills 11个入口、DirectorSKILL 1个入口、Director Suite 13个入口已在整理者本机安装；这不是克隆本仓库后的自动安装状态。它们也不作为本仓库的依赖捆绑分发。

本地安装检查中，drama-skills的17项自检通过。Director Suite在UTF-8模式下仍有两项包检查失败，指向同一处README旧版本号残留；这只是当次安装的记录，不代表上游当前版本状态。

没有对这些工具进行统一的生产质量评测，也没有验证笔记所述所有功能。实际出片应记录服务入口、模型版本、参数、参考、费用和结果，再形成可复用经验。
