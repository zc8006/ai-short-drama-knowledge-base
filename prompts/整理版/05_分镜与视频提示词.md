# 分镜与视频提示词：10 秒 / 15 秒统一模板

适用于已经完成的「旁白推文」或「对白短剧」。先把当前剧本拆成分镜，再把已采用的分镜转成视频提示词。本文件只产出文本，不上传素材、不调用生成服务、不提交付费任务。

本版整理自：`仿真人分镜10s带人物站位.txt`、`仿真人分镜头15s带人物站位.txt`、`镜头提示词 10秒.txt`、`镜头提示词2   15秒.txt`、`小说转分镜（直播用）(1).txt`。原文件保留。

## 1. 使用前填写

| 项目 | 填写方式 |
|---|---|
| 剧本来源 | 当前采用的剧本文件、场次和段落；不要混用旧稿 |
| 叙事路线 | 旁白推文 / 对白短剧，沿用上游选择 |
| 片段时长 `duration` | 10 或 15，整条任务统一填写；特殊片段另行说明 |
| 画幅 | 9:16 / 16:9 / 已确认的其他比例 |
| 视觉形态 | 2D 动画 / 3D 动画 / 真人写实，选定一种并写具体材质、光线与色调 |
| 输出语言 | 默认中文；人物口语语言按剧本填写 |
| 声音方式 | 模型原生声音 / 后期配音与音效 / 暂未确定 |
| 字幕 | 默认后期添加；视频画面不直接生成字幕 |
| BGM | 默认后期决定；需要时另列音乐意图，不把「有配乐」与「不要配乐」同时写入正文 |
| 参考方式 | 真实参考图 / 挂图计划 / 用户明确选择文生视频 |
| 目标服务与版本 | 已知则填写，未知写「待选择」，不据此声称模型能力 |

`duration=10` 和 `duration=15` 是这套模板的制作档位，不代表任何服务必定支持相应时长、切镜、音频或参考方式。实际生产前核对所选服务的当前能力；不支持时先修订分镜与交付方案。

**提示词不主动填写清晰度、分辨率或画质档位，由用户在生成端控制。** “细腻”“电影感”应落实到光线、材质与构图；本文件只编写文本。

## 2. 镜头怎么拆

1. 按情节变化、观众需要看清的信息和人物反应决定切点。一个片段可以是一镜到底，也可以包含多个镜头；切镜必须带来信息、情绪、空间或节奏变化。
2. 先安排对白、旁白、停顿和动作，再计算镜头时长。以人物的自然语速估读，预留呼吸、动作和末尾反应时间；不套用固定字数上限。
3. 声音和动作放不下时，增加片段或在已确认的边界拆镜。不要靠加速念词、增加每秒切镜数、删掉核心台词来硬塞。
4. 不强制 4—6 镜，不强制 20 个大段或每段 20—30 个 Cuts；也不要求无对白镜头必须小于 3 秒。
5. 景别服务于信息。交代空间可以使用全景，交代关系可以使用双人中景，观察反应可以使用近景。对话可用稳定双人镜头、过肩或正反打，不必机械交替。
6. 各片段从 0 秒重新计时，镜头区间连续、不重叠、不留无说明的空档，末端恰好到 `duration`。全片另列累计时间，不能把片段内时间和全片时间混写。
7. 同一动作只发生一次。上一镜已经接过钥匙，下一镜就从持有钥匙开始，不能再接一次。
8. 剧本中的留白可以保留。环境音、对白、旁白各有作用，不为了填满听觉而补写新旁白或新台词。

旁白推文按上游已确定的人称和叙述方式执行；对白短剧以人物表演与对白推进。不要在分镜阶段把第三人称旁白统一改成第一人称独白，也不要把旁白强行改成角色开口说话。

## 3. 连续性与参考图

### 固定编号

- `CHAR-001`：角色身份。
- `LOOK-001`：角色造型，必须同时写所属 `CHAR-001`，不把换衣服当成新角色。
- `SCN-001`：场景及其固定空间锚点。
- `PROP-001`：关键道具及其状态。
- `SEG-001`：拟作为一条生成任务的制作片段，包含一个或多个镜头；是否能装入同一任务，须核对实际服务能力。
- `SHOT-001`：镜头；修订时保留未受影响镜头的编号。

上游剧本节拍沿用 `BEAT-001`，可以写进镜头来源；它描述剧情节拍，不等同于 `SEG-001` 生成任务片段。编号用于跨文档关联，旁边必须有中文名称；不要只靠编号描述可见画面。

### 先锁场景，再写画面左右

每场先写固定空间：门、窗、桌、走廊出口在哪；人物相对这些锚点的位置、距离、朝向和移动路线；摄影机在轴线哪一侧。再根据具体机位写画面左、中、右与前、中、后景。

画面左右是机位投影，不等于场景固定坐标。人物不动但机位改变时，画面位置可能改变；应解释该机位与轴线的关系，不能把所有镜头的左右位置死锁成一条规则。需要越轴时安排可见的过渡或中性机位。

逐镜写清：视线看向谁或什么；左手、右手各做什么；道具由谁持有、在哪只手、何时接触或落下；光线、衣服、门窗和道具状态如何承接。交接、换手与放置要在画面中有过程。

### 真实参考与计划分开

| 标记 | 含义 | 记录要求 |
|---|---|---|
| `REF-001` | 当前实际存在、可读取且已核对内容的参考文件 | 路径、中文名、挂载顺序、用途、控制范围、不得控制的范围 |
| `PLAN-001` | 尚无真实文件的挂图计划 | 需要哪张图、对应资产或镜头、用途、计划顺序、待补内容 |

登记示意：

```text
REF-001（顺序：1）· {经核对的实际文件路径}《{中文名称}》（用途：身份；控制：面部身份；不得控制：本镜站位与动作）
PLAN-001（计划顺序：1）· SHOT-001《本镜冻结起始画面》（用途：起始帧；控制：人物站位、持物和构图；待补：真实图片）
```

花括号是模板占位符；填写前不构成真实素材登记。仅有图片提示词、文件名相似或“以后准备上传”均不能写成 `REF-001`。

`PLAN-001` 可以用于编写文字草稿，但不是已准备好提交的素材。只有用户明确选择不用图，才能改走文生视频；文生正文需写足人物、造型、场景、构图与光线，不能只说“保持参考一致”。

本地 `REF-001` 与平台的 `@图片1` 没有天然对应关系。平台实际上传完成后，才按界面显示建立映射；本文件不会把尚未上传的图写成已经绑定的 `@` 标签。实际服务是否支持多图、首帧、首尾帧、续接及其组合，留到生产前核对。

## 4. 可复制：剧本转分镜

替换输入项后，将下面整段交给 Codex；输入资料可以粘贴正文，也可以填写真实文件路径。

```text
请把当前采用的剧本制作成《分镜.md》，只写文本，不生成媒体。

输入：
- 当前剧本：{文件路径或正文}
- 叙事路线：{旁白推文 / 对白短剧}
- 视觉设定：{角色、造型、场景、道具资料}
- duration：{10 或 15} 秒
- 画幅：{比例}
- 视觉形态与光色：{唯一的已确认方案}
- 参考资料：{经核对的真实文件 / 挂图计划 / 用户明确选择文生视频}
- 上一片段结尾：{真实已知状态；第一段写“无”}
- 声音方式、字幕与 BGM：{已确认选项，未知如实写待定}

要求：
1. 沿用剧本的事件、人物、台词和叙述人称，注明来源场次或段落。缺失信息单列，不编造全本已解析或上游已确认。
2. 片段用 SEG-001，镜头用 SHOT-001 连续编号；角色、造型、场景、关键道具分别沿用 CHAR、LOOK、SCN、PROP 编号。LOOK 必须关联 CHAR。
3. 每场先写空间锚点、人物站位、轴线与摄影机工作侧，再逐镜写画面左右、纵深、朝向、视线和双手持物。写清哪一镜发生位置或道具状态变化。
4. 按叙事需要选择一镜到底或多镜，不限定镜头数量；不要强制正反打、禁止远景或用微动作凑镜头。
5. 每镜写唯一职责、来源、片段内时间区间、景别、机位、运镜及理由、可见起点、主要状态链和可验证终点。下一镜承接上一镜的终点。
6. 对白逐字保留，格式：角色名（语气、状态）说：“台词”。语气贴合人物，可自然重复，不为换词改变表演。
7. 画外音注明来源与说话人；内心独白/旁白不要求画内人物做说话口型。只有当前可见的实际说话者需要相应口型；不要把自然呼吸、表情变化也一律禁止。
8. 自然估读每句声音，写出发声窗口及依据，留出停顿、动作和反应。放不下就新增片段或提出剧本修订建议，不机械卡字数、不加速念词、不擅改台词。
9. 分开写环境音、动作音、对白/画外音与配乐；无须出现的层写“无”。如果确定后期配音，不同时要求模型生成同一份语音。
10. 每镜写一段冻结关键帧提示词，仅描述起始瞬间可见的状态；确有需要时另写收尾关键帧提示词。不要把起点、动作过程、终点塞进同一张图。
11. 参考文件核对后才写 REF-001；没有真实图片则写 PLAN-001 或缺口，不伪造路径与平台 @ 上传标签。列出每图用途、控制与不得控制范围。
12. 10/15 秒只是本次制作档位，不保证所选服务支持。只交付文本，不提交生成。提示词不主动填写分辨率或画质档位，生成端清晰度由用户控制。
13. 发现原文难以直接呈现的内容时，提出保留情节因果的画外处理、反应镜头或省略方案；不得声称替换某几个词就能保证审核通过。

交付《分镜.md》：先列片段规划与每场站位，再按 SHOT 逐镜输出；最后只列真实未决项。
```

2026-10-23起，面向平台粘贴的完整指令按 [08_视频生成指令格式.md](08_视频生成指令格式.md) 输出。本节保留阶段交接与编号要求；在每个片段的可复制正文内采用新格式。

要求：
1. 保留 SEG 和 SHOT 编号、时间轴、人物站位、机位、动作边界与台词，不在本阶段换导演方案或补剧情。发现时间放不下、动作冲突或缺信息时，先标记需修订的分镜。
2. 每片段先写素材清单与状态。真实 REF 才能声明文件已就绪；PLAN 下的文字是草稿，不可直接提交。缺图不得静默改成文生视频。
3. 不假装已经上传参考。只有真实平台界面核对完成后才建立 REF 与平台标签映射；未核对时正文使用人物/道具中文名，不编造 @图片1。
4. 可复制正文按08格式组织：基础参数 → 核心人物与环境锁定 → 分镜时序脚本 → 硬性约束。每镜写时间、景别与运镜、动作、对白、音效、镜头收尾；多镜逐镜写切点，单镜明确连续拍摄。
5. 每片段正文自足，不能只写“同前”。服装、光线、空间与关键道具沿用当前视觉设定。不要同时要求 2D、3D 和真人皮肤效果。

7. 逐字文本放在各镜的对白栏并注明发声窗口，同一句台词只写一次；动作段引用对应声源、关键词及发声时段。若另列声音总览，只引用声音事件，不再重复逐字台词。对白有语气，旁白/内心独白标注画外音与来源，不带动无关人物口型。
8. 台词窗口按分镜的自然估读结果复核，动作与停顿也占时间；不能用“总计正好 10/15 秒”代替说得完的检查。放不下就退回拆片段，不加速。
9. 选择模型原生声音时才写对应生成声音指令；选择后期配音时只保留声音后期清单，不重复要求模型念台词。字幕默认后期添加，正文写明全片不生成非画内字幕与对白文字叠加；画内标牌单独遵循剧本。
10. 配乐按选定方案只写一次；环境音和动作音不等于 BGM。允许安静和留白，不凭空加解说或音乐。
11. 本文档是通用文字稿，不声称服务支持 10/15 秒、多镜、首尾帧、多图或声音。投产前按真实平台能力转换与核对；提示词不主动填写分辨率或画质档位，实际生成设置遵循用户当次选择。

输出：按 SEG 列出拟交付片段，每段引用所有 SHOT，给出清晰时间轴、素材状态、可复制视频正文、声音清单与前后衔接。未定项留在正文之外；占位符未填、参考缺失或能力未核对的片段标记为“草稿，不可提交”。

## 6. 10 秒时间轴小例子

仅演示时间分配与动作连续性；人物和事件均为原创。这个例子采用对白短剧、真人写实、9:16、后期配音，无生成内嵌字幕或 BGM。`duration=10`；不作为已获生产授权的任务。

原始小场景：女孩收到一封附带旧钥匙的信。信已打开，她从信封里取出钥匙，循着钥匙齿形抬头，发现走廊尽头的旧门锁孔与之相似。
