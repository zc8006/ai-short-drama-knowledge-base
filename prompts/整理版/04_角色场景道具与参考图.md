# 04｜角色、场景、道具与参考图

用途：从小说或剧本整理视觉资产，再写参考图提示词。适用于“旁白推文”和“对白短剧”两条流程。本文件只提供模板，不代表已有图片，也不执行出图。

建议先完成《视觉设定.md》，再据此完成《图片提示词.md》。尚未明确的外观可以提出设计建议，不能写成原著事实。

## 一、编号和使用边界

- 人物用 `CHAR-001`，地点用 `SCN-001`，道具用 `PROP-001`；同一人物的不同称呼归并到一个人物 ID。
- 造型用 `LOOK-001`，必须连同人物 ID 使用，例如 `CHAR-001 / LOOK-001`。换衣、不同年龄阶段、持续伤势增加造型或状态，不把同一个人拆成多个身份。
- `REF-001` 只登记真实已有的图片，并写清路径及控制范围；没有图片时写“无外部参考”。`PLAN-001` 只表示待制作、待挂图的计划，不冒充图片引用。
- 图像尺寸、画幅和模型另行指定，尺寸未定就标“待定”。不要把画质形容词当作参数。后续视频默认 **768p**，提高分辨率须得到用户明确同意。
- 以下代码块是可复制的任务模板，使用时替换方括号。最终图片提示词正文要落实成具体描述，清除占位符。

## 二、可复制：资产提取模板

```text
请依据我提供的小说或剧本，整理《视觉设定.md》。本轮只整理文字，不生成图片，不编写分镜。

输入：
1. 原文或剧本：[粘贴内容，或指定文件及章节/集数范围]
2. 已确定的时代与主视觉：[填入；未定则标待定]
3. 已有视觉设定：[文件或无]

处理规则：
- 分开标注【原文事实】【可见推断】【设计建议】。事实附章节、场次或短引文依据；推断给出理由；建议留在待定区，不能直接当成已确认设定。
- 提取具名人物、重要无名人物及第一人称“我”。用称谓、关系和上下文归并代称；指代不明列为未决，不强行合并。无名路人可按功能成组记录，关键人物单列。
- 年龄、性别、身高、发色、瞳色等原文未明就注明“原文未明”；必要时提出可选年龄段或外观建议，不能伪称原文给出了具体数字。
- 不为了区分角色随意改掉原著服装；可用脸型、发型、轮廓、色彩或配饰提出辨识建议。人物性格只转换为可见的体态、神态或造型线索，不替代人物身份描述。
- 道具保留反复出现物、身份标志物，以及只出现一次但承担证据、转折、行动或情感作用的物品。普通无剧情作用的杂物可归入场景陈设。
- 地点代称归并；不同时间、天气、光态或陈设变化写为同一地点的状态。明确门窗、出入口、固定家具和前中后景锚点，保持空间关系可复用。
- 白底只用于角色和道具设定图。地点保留实际建筑、地形和环境；无人场景板的要求不能扩展成“所有剧情镜头都禁止出现人物”。
- 只锁定跨镜头需要保持的可见事实。单镜的站位、视线、左右手动作交给分镜；会持续限制动作的伤势、束缚、负重或持物关系要记录生效范围。

《视觉设定.md》按以下结构输出，未出现的信息不要硬填：

一、视觉方向
时代依据、选定风格、主色与材质、待定项。

二、人物档案（逐人分段）
CHAR-001｜姓名或功能称呼
代称：全部已确认代称；含混称呼另列。
原文事实：外观、身份及来源。
识别锚点：少量稳定、可观察的脸部/发型/体态特征。
可见推断：内容及理由；没有就写无。
设计建议：待确认的外观补足；没有就写无。
造型 CHAR-001 / LOOK-001：适用集数或场次；头发、上衣、下装、鞋、配饰及状态。
其他造型/年龄阶段：变化原因及持续范围；身份锚点保持一致。
连续性锁：只列必须保持的可见事实。

三、地点档案（逐地分段）
SCN-001｜有辨识度的地点名
代称、出现依据。
固定布局：空间尺度关系、出入口、标志性建筑/家具、前中后景锚点。
场景状态：适用场次、时段、天气、光线、可变陈设。
可见推断与设计建议分列。
需要的参考视图：说明视角及空间关系，不写成已存在图片。

四、道具档案（逐物分段）
PROP-001｜道具名称
出现依据与剧情用途。
识别锚点：形状、材质、颜色、相对尺寸、可读标记（仅原文明确时）。
归属与状态：持有者、开合、完整/损坏、状态变化及适用场次。
可见推断与设计建议分列。

五、连续性与未决项
列出跨场状态变化、含混身份、原文冲突和待定设计；不把待定建议写入已确认锁。

六、图片登记与制作计划
真实已有图片：仅在确实提供图片时登记 REF-001、路径、对应资产、用途、控制范围及不得控制范围；否则写“无外部参考”。
制作计划：用 PLAN-001 标记拟制作的角色板、地点板、道具板及用途；状态写“待制作”。
不要虚构图片路径、核验结果或已生成状态。
```

## 三、精简风格卡：每次选一个

将选中的一张卡放入后面的提示词模板；角色、场景和道具保持同一视觉体系。改风格时另列候选，不在同一张图里混用三种媒介。

| 选项 | 可复制风格卡 | 适用边界 |
|---|---|---|
| 2D | 2D 动漫设定图，线条清晰，色块稳定，适度赛璐璐明暗，服装结构与人物轮廓明确。 | 不同时要求真人摄影皮肤或三维游戏材质。 |
| 3D | 3D 动画角色设定图，三维体积明确，材质与布料层次可辨，皮肤、头发和服装使用统一的渲染方式，柔和中性照明。 | 数字角色；不自动加入手办、BJD 或塑料皮肤。 |
| 真人写实 | 真人写实设定照，自然人体比例，保留皮肤纹理、真实发丝与服装面料，中性摄影光线，面部和衣物清晰可辨。 | 统一采用摄影外观，不叠加二次元、厚涂、CG 建模等要求。 |

古风、都市、末世属于时代或题材，需叠加到所选媒介上。冷峻、温柔等气质要落实到具体眼神、神态或姿态；不要默认所有人同一肤色、体型或审美。

## 四、可复制：三视图设定图模板

```text
请根据《视觉设定.md》中已确定的 CHAR-[编号] / LOOK-[编号]，编写一条三视图图片提示词，写入《图片提示词.md》。本轮仅写提示词，不生成图片。

画幅：[指定比例；未定则标待定]
图像尺寸：[指定尺寸；未定则标待定]
风格：[只放入一张风格卡]
实际已有参考：[真实 REF 编号、路径及控制范围；没有就写无外部参考]

提示词结构：
同一个角色、同一套造型的三视图设定板，纯白背景，三栏等距排列，从左至右依次为正面、左侧面、背面全身视图；每栏展示从头顶到鞋底的完整身体，脚下留白。三栏是同一人物的三个视图，不是三个不同角色。身份特征为[识别锚点]；服装为[已确定的上衣、下装、鞋和配饰]；当前状态为[已确定的状态]。各视图的五官结构、发型、身高比例、服装结构、配饰位置与颜色保持一致。自然直立，双臂放松，平视、弱透视、中性均匀光照。背面不可见的面部不强行显示。无剧情动作、无多余人物、无额外道具、无文字、无标志、无水印、无界面元素。附上选定风格卡。

不要擅自添加档案里没有的年龄、发色、服装或装饰；未确认内容单列待定，不塞入最终可复制正文。
```

## 五、可复制：四视图设定图模板

四视图在这里指 **1 个面部特写 + 3 个全身视图**，不是再增加第 4 个全身人物。

```text
请根据已确定的 CHAR-[编号] / LOOK-[编号]，编写四视图设定板的图片提示词，写入《图片提示词.md》。本轮仅写提示词，不生成图片。

参数与外部参考：[按上一模板填写]
人物身份与造型：[从《视觉设定.md》引用已确定内容]
选定风格：[只使用一张风格卡]

提示词结构：
一张同一角色、同一造型的四视图设定板，纯白背景，严格只有四个区域：最左一栏是面部正面特写，右侧依次是正面、左侧面、背面三个全身视图。全图仅有一个面部特写和三个全身视图，不额外增加第四个全身视图。各全身视图从头顶到鞋底完整入画，等比例、对齐、互不遮挡。人物身份为[识别锚点]，当前造型为[服饰与状态]。所有视图保持同一脸部结构、发型、体型、衣物版型和配饰；面部特写与全身正面的脸一致。平视、弱透视、中性均匀光照。无表演动作，无多余人物，无文字、标志、水印和界面元素。附上选定风格卡。

若还需要面料、发饰或鞋子特写，另建局部细节板；本张四视图不自动塞入额外网格。
```

## 六、场景板与道具板的写法

**场景板**：`SCN-[编号] 的[指定状态与视角]，用于环境参考。[地点、固定布局、时段、天气、主光源、前中后景锚点和材质]。保留完整环境空间。此张参考板不安排演员或人物，不加漂浮文字、标志和水印。[选定风格卡]。`

“此张参考板无人”只约束环境底板。后续有人物的分镜仍应写明人物 ID、站位、动作和持物；场景名称或元数据可以引用人物关系，画面正文用可见环境描述，不让人名替代建筑与布局。

**道具板**：`PROP-[编号] 的[指定状态]，单独完整展示在纯白背景上。[外形、材质、颜色、相对尺寸及稳定识别特征]，柔和中性光，无手持遮挡，无额外物品，无文字、标志和水印。[选定风格卡]。`

需要表达开合、破损等变体时，单独写状态图；需要人物拿取道具时，转到有具体动作的分镜，不把手部动作塞入纯道具板。

## 七、《图片提示词.md》输出格式

每张图一项，沿用稳定的 `IMG-...` 条目编号；资产 ID、造型和状态写在元数据，最终正文不含路径、流程说明或“已核验”之类结论。

```markdown
## IMG-CHAR-001-LOOK-001-TURN｜角色三视图
- 对应资产：CHAR-001 / LOOK-001
- 用途：人物身份与服装参考
- 参数：画幅待定；尺寸待定；模型待定
- 参考：无外部参考
### 可复制提示词
> 此处填写已落实身份、造型、布局与风格的完整提示词，不留占位符。
```

如果确有输入图，把参考行替换成真实登记，例如采用以下格式，删除占位内容后再使用：

```text
- 参考：REF-001（顺序：1）· [真实项目相对路径]《[图片名称]》（用途：[用途]；控制：[身份/造型/材质等具体范围]；不得控制：[不沿用的姿态/背景/构图等范围]）
```

图片条目完成不等于图片已经存在。真实图片取得后再登记 `REF-...`；候选图是否符合设定需单独核对，不能预填“身份一致、核验通过”。

## 八、交付前核对

- 人物代称已归并，年龄与身高没有把建议伪写为原文事实。
- 同一人物的不同衣装、年龄阶段与伤势有明确适用范围；角色辨识没有依赖任意换装。
- 关键的一次性剧情道具没有漏掉；道具归属、开合与损坏状态可追踪。
- 场景保留实际环境；无人底板与有人物的剧情镜头没有混为一谈。
- 三视图数量正确，四视图严格为“1 特写 + 3 全身”；全身完整、各视图衣装一致。
- 同一图只用一张风格卡；没有相互冲突的半身/全身、真人/动漫或背景要求。
- `REF-...` 均指向真实已有图片；待制作内容使用 `PLAN-...`。本轮交付仅为两份文字文档。
