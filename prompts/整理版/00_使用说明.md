# 短剧提示词工具箱 · 整理版

把故事做成旁白漫剧或对白短剧时，从这里选一条流程。原目录的 15 份 `.txt` 保留，整理版放在本目录，日后优先使用整理版。

这套文件提供写作模板和交付规范。它可以配合已安装的 Skills 使用，也可以复制到其他助手中使用；这里只编写文本，生成图片、视频和配音需要另行执行。

## 先选路线

| 需求 | 使用文件 | 主要产物 |
|---|---|---|
| 小说推文、主角自述、旁白讲故事 | [02_旁白推文流程.md](02_旁白推文流程.md) | 以旁白为主的 `剧本.md` |
| 人物对话、动作表演推动剧情 | [03_对白短剧流程.md](03_对白短剧流程.md) | 以对白和动作组成的 `剧本.md` |
| 整理人物、场景、道具，写参考图提示词 | [04_角色场景道具与参考图.md](04_角色场景道具与参考图.md) | `视觉设定.md`、`图片提示词.md` |
| 把剧本转成镜头和视频提示词 | [05_分镜与视频提示词.md](05_分镜与视频提示词.md) | `分镜.md`、`视频提示词.md` |
| 将采用的分镜整理成平台可复制指令 | [08_视频生成指令格式.md](08_视频生成指令格式.md) | 基础参数、锁定、时序脚本、硬性约束 |
| 为配音或程序导入拆台词和旁白 | [06_台词旁白JSON.md](06_台词旁白JSON.md) | 按需导出的 JSON 数组 |
| 交付前检查 | [07_交付检查.md](07_交付检查.md) | 问题清单或通过结论 |

全流程共同遵循 [01_通用规则.md](01_通用规则.md)。

推荐顺序：选路线写剧本 → 提取资产 → 写参考图提示词 → 拆分镜 → 写视频提示词 → 检查。已有哪一步，就从下一步开始。JSON 只在配音或程序导入需要时导出。

## 复制就能开始

在 Codex 中可以复制下面一段，替换方括号内的内容：

```text
请按 prompts/整理版/00_使用说明.md 使用工具箱，并读取01通用规则。
路线：[旁白推文 / 对白短剧，二选一]
素材：[文件路径，或随后粘贴正文]
本次范围：[只改剧本 / 只拆资产 / 只出分镜和视频提示词 / 完成文字前期]
输出目录：[新项目目录，或现有项目目录]
视觉风格：[2D动漫 / 3D动画 / 真人写实，三选一；只写剧本时可待定]
画幅：[9:16 / 16:9 / 其他]
目标集长：[秒数，或先按内容估算]
视频片段档位：[10秒 / 15秒 / 按已选服务能力决定]
改编权限：[忠实转写 / 允许精简重排；重要人物关系与结局变更需另列建议]
现有参考资料：[文件路径；没有则列出所需参考图计划]
只完成本次文字范围，不提交生成任务；提示词不主动填写分辨率或画质档位。
```

已知信息直接沿用；缺少非关键项时标注工作假设并继续。会改变故事主线、人物关系、结局或产生费用的决定，应根据用户实际授权处理。不要为填写模板重复询问已确认的信息。

## 与已安装 Skills 配合

| 工作 | 可用 Skill |
|---|---|
| 项目初始化、继续项目、跨阶段整理 | `$short-drama` |
| 长篇原著分析、改编和分集 | `$short-drama-novel-analyze`、`$short-drama-develop` |
| 写或改单集 | `$short-drama-write` |
| 资产、图片提示词 | `$short-drama-assets`、`$short-drama-image-prompts` |
| 分镜、视频提示词 | `$short-drama-storyboard`、`$short-drama-video-prompts` |
| 导演风格、摄影与调度 | `$cinematic-director` |
| 打戏、真人格斗、玄幻斗法 | `$sd-combat-engine`、`$sd-real-engine`、`$sd-xuanhuan-engine`，按任务选用 |
| 实际生成、剪辑 | `$short-drama-produce`、`$short-drama-edit`，在对应阶段调用 |

选择一个主流程，按需调用专用技能。不要把多套完整总控规则同时拼进同一条提示词。用 `short-drama` 套件时，让五份创作文档各自记录对应决定，JSON 和看板只是导出。

使用这些模板不要求复制或重新安装全部外部 Skills；工具来源见仓库文档。
