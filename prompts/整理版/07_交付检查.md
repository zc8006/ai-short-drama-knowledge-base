# 交付检查

按本次范围检查，缺少未请求的阶段不算错误。以下清单检查文字、引用和参数；媒体生成后的表演、口型、空间和画质需要看片确认。

## 可复制检查指令

```text
请按本工具箱01通用规则和以下检查项，检查【文件路径/项目目录】。
本次范围：【剧本/资产/分镜/视频提示词/JSON/已有生成素材】。
只读检查。列出问题位置、冲突规则及最小修改建议；不自动改写来源文件。
对尚未生成或未能读取的媒体标“未验证”，不要用文字自检通过代替看片验收。
```

## 故事与声音

- 路线明确，旁白推文与对白短剧的声音安排与上游剧本一致。
- 已注明忠实转写或精简改编；改编建议未混入原文事实。
- 没有未读就声称分析全书，没有丢失关键因果或加入无来源台词。
- 说话人、对白与画外音分清，只有正在说对白的人需要对应口型。
- 台词有估读或试读时长，保留动作、呼吸、停顿和反应所需时间；总时长超预算时有拆分或修改建议。

## 资产与参考图

- 角色代称归并，年龄/服装变化对应具体造型；未明信息标出推断或建议。
- 一次性关键道具仍被收录，持物手、位置和损坏等状态可延续。
- 场景有可定位的空间结构；角色/道具白底规则没有误用于完整环境。
- 视觉风格统一。参考图ID能定位实际文件，计划ID不冒充已完成素材。
- 三视图为3个全身方向；四视图为1个面部特写加3个全身方向，数量与描述一致。

## 分镜与视频提示词

- 可复制正文符合08格式，逐镜包含时间、景别与运镜、动作、对白、音效和收尾；总览与正文一致。
- 表演变化由角色实际获得的信息触发；动作和对白不重复，语气与人物关系一致。

- 同一片段的时间从0开始，镜头区间无重叠、无未说明空缺，末尾等于该片段时长。
- 10秒和15秒没有混写；镜数按故事需要选择，未为凑数重复动作。
- 镜头ID唯一，所属片段明确。相邻镜头的动作起止、人物朝向、视线与道具状态能接上。
- 机位变化遵守当前空间关系；有意越轴或跳切时写明用途与重新建立空间的办法。
- 每镜动作、表演和相机行为可执行，不靠“电影级”“大师级”替代具体指令。
- 视频提示词的挂图计划与真实素材区分，角色映射只包含当前片段实际角色。
- 字幕、画面文字、BGM、环境音与动作音分别有说明，未互相覆盖。

## JSON导出

- 遵循06文件的字段、类型、长度和码点索引口径。
- 全文模式逐字符还原来源；仅声音模式只承诺选定声音文本的完整性。
- 标点、空格、换行可还原，没有错配角色或凭空补充内容。
- 导出与当前剧本版本一致；修改剧本后重新导出，不在两处独立改剧情。

## 生成任务提交前

只有进入实际媒体生产时才执行这一组检查：

- 核对本批内容、任务数量、时长、画幅、参考图及声音设置与当前授权一致。
- **实际生成设置遵循用户当次选择；提示词不主动指定分辨率或画质档位，不擅自更改用户设置。**
- 核对所用模型/服务在当前入口的时长、参考方式与参数支持；无支持项列明缺项，不静默升级模型或提高分辨率。
- 核对真实上传顺序与平台显示的图片标记。不要把本地REF编号直接当成平台已经接受的`@图片`序号。
- 有现成候选时先查看状态和用途，不因改模板或降分辨率重复提交。

## 交付结论

用下面的短格式报告即可：

```text
已检查：文件/范围
结果：文字检查通过 / 有待修项 / 输入不足
问题：位置 + 原因 + 最小修改建议
尚未验证：试读/图片一致性/视频表演/口型/剪辑等实际未做的项目
```

只完成文字时，不写“已成片”“审核必过”或“人物一致性已验证”。
