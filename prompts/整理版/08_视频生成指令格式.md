# 视频生成指令格式

更新：2026-10-23。来源：用户指定的 Seedance 指令排版与邀舞误会试片迭代。状态：文字修订，尚未以本模板完成系统性出片验证。

适用阶段：已有采用的剧本与分镜，将它们整理为可复制的平台视频指令。输入是当前剧本、分镜、参考素材及已知参数；输出是一条或多条完整指令。保留 [05模板](05_分镜与视频提示词.md) 的连续性与素材核对要求。

## 固定格式

按以下顺序输出：

1. **视频生成指令标题**：模型、时长、画幅。
2. **基础参数**：视觉风格、镜头结构、对白语言、字幕、配乐、旁白及连续性。
3. **核心人物与环境锁定**：每张参考的对象、用途与控制范围，必要的空间、服装、持物和光线。
4. **分镜时序脚本**：每镜标题包含编号、起止时间、景别与运镜；正文依次写动作、对白、音效、镜头收尾。
5. **硬性约束**：只保留本条视频确有必要的动作、表演、连续性、声音与文字要求。

镜数、硬切次数、运镜、时长、风格及对白语言根据项目确定。不能因为示例是15秒三镜两切，就把所有剧情都改成三镜；奔跑、急刹、喘气和表情也不是固定配置。

## 写作要求

- 不主动写清晰度、分辨率或画质档位，由用户在生成端控制。
- 时间段连续且总长一致；依据自然语速和动作负载规划，不以“精准时间轴”承诺模型逐帧执行。
- 一镜写清起始关系、触发、动作过程、反应与终点。先写人物距离、朝向和路线，再写机位；固定机位与移动跟随不能同时含糊指定。
- 相邻镜头承接同一次动作，跨镜对白连续且不重复起句。每句完整台词只出现一次；分镜总览可引用声音事件，避免再次抄写整段对白。
- 情绪变化跟随角色获得的信息。关键词前保持原有理解，听清后才产生新的反应；嘴角、眉眼、呼吸等变化自然连贯，不能提前预演。
- 对白写明说话人、口语语言、语气和画内/画外位置；动作段可引用关键词，不将关键词另列为新台词。只有实际说话者产生说话口型。
- 环境声、动作声、对白、旁白和配乐分别指定。停止走路时脚步声停止，环境声可继续；无配乐不等于无环境声。
- 参考图沿用身份、造型、环境和构图各自职责。用户自行挂图时注明顺序计划，使用前按平台实际标签替换，不声称已经上传。
- 保留已确认剧情与对白；格式化不自动授权新增台词或夸张动作。
- 分镜总览或表格需要时保留，并与正文同步。明确它们共同描述一套方案、只执行一次。
- 可复制正文清除流程说明、失效引用、截断来源字样及未填写的占位符。
- 已选导演参考应转为具体的距离、视线、调度或摄影方法；导演姓名不能替代动作设计。
- “无水印”可按用户要求写入，但提示词不能保证控制平台自带水印。
- 长篇交付优先保存Markdown并给出链接，按用户要求决定是否在聊天中粘贴全文。

## 可复用骨架

下方是写作模板，花括号须在交付具体指令前替换；可按实际镜数复制镜头区块。素材状态、待核对项和估时依据放在指令外。

```markdown
### 视频生成指令（{模型}，{时长}，{画幅}）

#### 基础参数

时长：{秒数}；画幅：{比例}；模型：{已选模型}。
视觉风格：{具体风格、光线与质感}。
镜头结构：{镜头数量与切镜方式，或一镜到底}。
对白语言：{按剧本}；字幕：{设置}；配乐：{设置}；旁白：{设置}。
跨镜保持人物身份、服装、空间和受光连续。

#### 核心人物与环境锁定

人物：{角色名、对应参考、关键身份和造型、持物状态}。
环境：{场景参考、门窗等空间锚点、时段与光线}。
参考范围：{每张图控制什么、不控制什么}。
初始关系：{人物前后与横向距离、朝向、起始动作}。
表演方向：{人物目标、关系和可见行为}。

#### 分镜时序脚本

【镜头1｜{起秒—止秒}｜{景别与运镜}】

动作：{可见起点 → 触发 → 具体动作及反应 → 终点}。
对白：{说话人、口语语言、画内/画外、语气及逐字台词；无则写无}。
音效：{环境声、动作声与对应动作；必要的声距变化}。
镜头收尾：{切点依据、动作承接、跨镜声音连续性}。

【镜头2｜{起秒—止秒}｜{景别与运镜}】

动作：{承接上一镜终点，本镜动作与表演变化}。
对白：{本镜实际发声；跨镜句只写尚未说出的部分}。
音效：{声音延续或变化}。
镜头收尾：{结束状态或下一切点}。

#### 硬性约束

1. {镜头结构、轴线与视线连续性}。
2. {人物数量、身份、服装、道具与受光连续性}。
3. {动作过程、接触、位移及物理边界}。
4. {表情触发点与对白顺序，避免提前反应和重复台词}。
5. {本条确定的字幕、配乐、旁白、环境声等要求}。
```

## 已填写的小例子

仅示范格式，不是已采用的邀舞剧本，也未提交生成。两个说话者均为原创，假定用户已在自己的工具中挂好人物与场景图并核对标签。单镜也使用相同结构。

### 视频生成指令（Seedance 2.0 Fast，10s，16:9横屏）

#### 基础参数

时长10秒，16:9横屏，真人实拍质感。一镜到底，固定机位。中文对白，无字幕、配乐和旁白，保留办公室环境声。

#### 核心人物与环境锁定

林岚参考@图片1，同事参考@图片2，办公室参考@图片3。保持参考中的面孔、发型、服装和窗光。林岚坐在桌后，右手握笔准备在摊开的文件上签字；同事站在桌侧约一米外，双手空着。人物图控制身份与造型，场景图控制桌窗位置和光线。

#### 分镜时序脚本

【镜头1｜0—10s｜双人中景，固定机位】

动作：林岚把笔尖移到签名位置。同事提醒时，她先继续看文件；听清“昨天”后，笔尖停在纸上方，抬眼看同事。她问完后把笔放回桌面，文件仍留在原处。
对白：约1—4秒，同事用中文平静地说：“等等，这是昨天那一版。”约5—7秒，林岚抬眼用中文问：“新的在哪里？”
音效：轻微通风底声，衣料摩擦；笔放回桌面时发出轻响。
镜头收尾：保留她等回答的短暂目光，直接结束。

#### 硬性约束

1. 全片一镜到底，人物不因说话换位。
2. 只有一支笔，始终由林岚右手持有，之后由她放回桌面。
3. 听清“昨天”后才停笔抬眼，不提前反应；笔尖不先落纸签字。
4. 两句对白各说一次，只由实际说话者做口型。
5. 无字幕、对白文字叠加、旁白和配乐；保留环境声与动作声。
