# 《断网之后》六集剧本审查与追更卡点

审查底稿为《03 (1).md》。追更强度是基于剧本阅读的判断，实际效果待试读和试剪。

第1集的裁员题材最容易让人点开，第3集的雨中求援最能让人追下一集，第4集到第5集最容易掉人。全季最有力的是人物关系的倒转：当众裁掉周衍 → 专家救不了 → 总裁亲自求他 → 贺凯跪着托电脑。后半季若连续加入「AI是他写的、危机是他设计的、百亿美元归他」，会冲淡这条人物线。

## 二、全季问题

### 1. 周衍究竟在救什么

前四集把全城停摆与主账本被删设为真实危险，第5集揭晓真正账本安全，第6集又靠最后一秒复网。如果周衍早就能恢复，观众会追问他为何等裴元加仓、让支付和地铁持续停摆。这会动摇观众对周衍的认同。

建议保留真实停摆。周衍提前保护了账本，但业务通道确实被锁，必须回机房才能恢复。蜜罐负责诱捕木马和留存证据。采用这个方向后，最后一秒的后果也要写清楚，让观众知道失败会失去什么。

### 2. 时间轴与倒计时

| 位置 | 当前问题 | 修改方向 |
|---|---|---|
| 第1集 | 00:00启动1800秒，00:01出门的结尾却仍报1790。 | 将出门和大厅警报并行剪辑，按实际经过时间统一屏显。 |
| 第2集 | 00:15标1200→600，正常走15分钟应剩900。 | 保留1200→600时，将探针触发升级提前到00:10。 |
| 第3至4集 | 按原稿00:15剩600，应在00:25归零，00:26却还有400秒、00:30仍有180秒。 | 重排车程、求援、协议和远程挂起。若00:10减至600，00:16剩240，约00:17:30到150。车程和出发地应匹配这条线。 |
| 第5至6集 | 150已挂起，后续却直接出现03秒，且03到01之间夹着转场和长对白。 | 在机房拍清谁恢复计时、为什么必须恢复。最后03、02、01按同一个连续动作处理。 |

### 3. 人物动机与变化

- **周衍**。先确认能不能保账，再谈权限和追责。保留克制、旧键盘和夜钓反差，缩短带惩罚意味的拖延。
- **秦岚**。第1集亲手叫停回滚，第3集承认这个决定，第6集公开披露自己的审批。让她的道歉和承担落在具体行动上。
- **贺凯**。后半段主要在挨打、挨骂和昏倒。可在第3集被问及倒计时泄露时先遮腕表，第5集听到日志留存时再次护住它，让第6集的签名揭晓有迹可循。
- **魏哲**。第2集失败、第4集继续嘴硬、第5集拜祖师，变化过急。先让他承认损坏机柜，再主动报校验或协助小川。
- **唐小川**。让他接过键盘、找到老港、保全日志。三个动作可以贯穿全季，减少重复提醒和赞叹。

### 4. 商战规则与证据

- **上市与夜盘**。稿中说云澜下月海外上市，当晚却已有夜盘和公开做空。先交代现有上市主体和拟上市主体的关系，或把压力改成融资、收购报价。
- **百亿美元交割**。原稿缺少秦岚的救援协议如何决定对手方爆仓款去向的设定。这段抢过了内鬼揭晓的注意力。股权承诺也需要有从紧急签约到正式审批的过程。
- **证据链**。第2集可露出一条审批来源不明的发布记录，第3集让裴元说出外界不该知道的剩余时间，第5集保全原始日志，第6集再用发布签名、资金凭证和提前埋下的通信或录音串起来。
- **反转顺序**。第4集只露测试版，第5集用物理密钥认出Zero，第6集确认谁批准木马入库。每集揭晓一件能改变局势的事。

### 5. 分镜前应补齐的可见动作

| 段落 | 剧本需要写清的动作 |
|---|---|
| 大厅裁员 | 先读到0001，再听见踩裂和裁员。之后给小川想拦又停、周衍自己蹲下、内芯在掌心一闪。看台、主控台和副台的视线要对上。 |
| 回滚争执 | 写清谁有权限、谁准备确认、秦岚开口时谁的手停下。贺凯按接管键要给完整的动作和授权反馈。 |
| 专家失败 | 让观众看到探针接入、进度冻结、终端拒绝、时间腰斩的顺序。火花只承担故障反馈。 |
| 海边托电脑 | 交代谁先拿终端、为什么放不稳、贺凯何时伸手、膝盖何时触地、谁最后稳住电脑。雨量、手位、设备和鱼桶的交接保持一致。 |
| 机房抢修 | 触控失灵、旧键盘接入、密钥认证、恢复计时、隔离木马各自有可见结果。单个镜头优先留一条要读的屏幕信息。 |
| 大屏揭证 | 依次亮出签名、资金、通信证据。给贺凯认出签名、裴元听到自己声音、秦岚承担审批责任留出反应。 |

车队可用少量车辆、远光和湿地反光交代。整楼红透、全息拓扑、集体鞠躬和喷血会提高制作量，也会把质感推离已经定下的真人写实风格。五场和对白字数可以做规格参考，实际集长要把演员停顿、下车走位、道具交接和操作时间纳入试读、试演。

## 三、改稿顺序

1. 定第5、6集的危机规则，写清周衍保护了什么、还必须救什么，以及最后一秒失败的代价。
2. 统一跨集时间线，再改第1集来电、第4集落键前悬停、第5集胜负未定这三个卡点。
3. 给第6集证据提前埋线，理清夜盘主体、救援协议与股权承诺。
4. 写细大厅裁员、海边跪递、机房抢修三场，再拆分镜。
5. 保留第3集夜钓反差与雨中鞠躬，缩短重复求情，让第4集开头立即兑现。
