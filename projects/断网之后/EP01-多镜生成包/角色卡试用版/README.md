# A段角色卡试用版

本版本用3张角色卡合并原6张定脸与造型图，因此A段从18张缩减到15张。按TXT开头清单上传15个图片文件。每张卡左右是同一人的两个视图，剧情画面只出现镜头指定数量的实体人物。

角色卡放在 assets/characters/，名称为 P01-EP01-CARD、P02-EP01-CARD、P04-EP01-CARD。原18图版仍可作为对照。第01镜完好起点和破损终点继续分别引用，第04镜收口袋的动作与台词沿用原处理。

卡内面孔取左侧大特写，服装、发型、眼镜和鞋取右侧全身；唐小川以首集卫衣、工装裤与背包为准。贺凯腕表按首集设定固定在本人左腕。

这次只生成三张角色卡，未提交视频任务。视频是否能准确取用双视图仍需实际生成结果确认。
