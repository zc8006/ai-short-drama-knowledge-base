# 《温柔的獠牙》EP01–EP02 剧情与制作交接

更新于 2026-11-16。用于继续第 2 集《借刀的规矩》的剧情修订、补拍和粗剪。各段时间码按对应源素材计算。

## 接手从哪里开始

1. 以第 1 集现有粗剪和第 2 集仓库逐镜稿为基线。先看「泳池湿合影 → 夜间合影与红名单 → 次晨巡逻新规」这一条跨集线，确认观众能认出合影、听清白栖在查什么。
2. 剪辑用已换挂钟的 `02_002` 作为当前素材底板。先试接两条已写好的 4 秒补拍，再确定出门补镜的入出点。两段尚未并片或验收。
3. 跑 `02_003`、`02_004` 前，先确定南智宥针对金多贞的动机放在哪一镜、金多贞透露的旧案信息放在哪一场。下表的剧情修补建议待定稿。

## 第 1、2 集怎么接

| 人物 | 现有剧情依据 | 待补强的交代 |
| --- | --- | --- |
| 白栖 | 被陷害禁赛的拳击冠军，伪装成 C 级学生入学，私下查姐姐白璐坠楼与红名单。第 1 集泳馆从水里捞出姐妹合影，夜里擦干合影并用中文汇报「我入学了，红名单还在」。 | 第一优先试用现有合影、电话和红名单画面把目的串起来。若试剪后仍看不懂是查姐姐，可在嘴不入画的镜头加一句中文画外音，例如「姐，你当年为什么会进红名单？我会查清楚。」这是拟增台词，需确认后再录。 |
| 南智宥 | 第 1 集在泳馆把白栖的包扫进水里。第 2 集检查口，她在打火机被搜出来后为了撇清更重的嫌疑，说漏自己指使跟班关人。 | 给她一拍说明为什么从白栖转向金多贞。优先在 `02_003` 镜02–03 两人私下交谈时提到「金多贞帮白栖」，再接制止跟班找打火机的原有动作。嫉妒可留在表演里，直接与金多贞被关的因果要听得懂。 |
| 金多贞 | 第 1 集与白栖相识。第 2 集用盲区图提醒白栖，午后被困后推不开门、听见外面脚步，获救只说「我推不开门，外面有人」。 | 保留救出当下的短句，让惊魂未定的状态成立。若采用「去年的 402 学姐」线索，放到后续安全环境单独交代。先定金多贞亲眼见过什么、从谁那里听说什么，再决定何时说出白璐名字。总企划已写金多贞住 C 栋 402，白璐是否与 402 有关仍需确认。 |
| 姜书沅 | 早上公布整点巡查。午后按规矩检查，在南智宥自曝后援引 S 级豁免例外，当众扣 50 分。放学拿弯发卡与检查时看到的湿袖口试探白栖。 | 保留「整点巡逻 → 搜出同一枚打火机 → 南智宥自曝 → 姜书沅按例外扣分」的镜序。若要交代浓烟事件是否扩大检查范围，放在检查口开头简短补足，沿用已建立的整点巡查。 |

### 两条道具连续性

- **打火机**：`02_001` 跟班甲手里出现带焦痕的银色打火机 → `02_002` 白栖在器材室门边用纸巾拾起 → `02_003` 错身后，同一枚打火机从跟班甲黑色托特包外侧袋露头并被搜出。保持焦痕、包、外侧袋和跟班的中分低马尾一致。检查口的处罚依据是南智宥亲口承认指使关人。
- **发卡与湿袖口**：`02_002` 白栖手里是完整黑色 U 形发卡 → 喷淋后，敞开红柜的门沿锁孔留下一枚前端弯折的发卡，白栖袖口变湿 → `02_003` 姜书沅看到湿痕 → `02_004` 用弯发卡和此前湿痕追问，放学时袖口已干，可留淡褶。
- **结尾**：权限表与白璐的采访笔记指向月考封装负责人。随后只用银袖扣的手和 `백서 / RED LIST` 候选预警收尾。谁在操作、是否改分留待后续揭晓。

## 合剪验收

- 第 2 集仓库基线为 25 + 27 + 26 + 26 = **104 秒**。替换长于源区间时重新计算。生成按整条补拍最少 **4 秒**规划，内部子镜头按叙事切分。
- 白栖、金多贞左胸保持空白。核对不同机位上的站位、目线和袖口干湿，特别是 `02_001` 走廊与 `02_002` 救出后的切点。
- 校园对白保持韩语，白栖内心独白为中文并闭口。回听完整台词音轨及口型，图表和必要文字在后期复核，画面避免自动字幕、水印和 BGM。
- 现有成片按源规格导出。除分辨率、帧率和时长外，核对平均视频码率、音频是否被转码，以及替换镜头的首尾帧。
