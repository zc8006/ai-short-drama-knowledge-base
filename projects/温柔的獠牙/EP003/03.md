## 二、逐段分场剧本（含动作、机位与双语对白）

### 第一段 `03_001`｜纸飞机冷开场 + 放榜交代红名单规则与白栖入榜（`28.0s / 12镜`）

1. **冷开场（`0.0–4.5s` · 镜01–03 · 守住前三秒钩子 · 纯音效零台词）**：

   * `0.0–1.2s`（镜01）：开镜纸飞机（`P13-PAPER-PLANE`，工整演算草稿纸折成、无“100%”字样）已经折好、刚从二楼栏杆前白栖指尖放飞离手。

   * `1.2–3.5s`（镜02）：纸飞机俯冲滑翔擦过广场电子排名大屏一角，屏幕底部赫然露出 **`백서 / RED LIST`** 红框（前三秒内直接砸出悬念钩子）。

   * `3.5–4.5s`（镜03）：纯黑过渡卡，后期叠字：**【月考放榜日】**。

2. **交代红名单规则与后果 + 多贞挤过来拉住白栖（`4.5–17.5s` · 镜04–09）**：

   * `4.5–11.5s`（镜04–07）：校门广场巨型电子屏（`s01_gate_screen_v2.png`）围满学生，大屏只保留 **`RED LIST`**，后期浮字：**`全校排名倒数三名`**；人群里学生议论（纯韩语）：`레드 리스트에 올랐는데 누가 쟤랑 같이 다니겠어?`（上了红名单，谁还敢跟她一块儿？）旁边几名学生下意识往后退了半步。

   * `11.5–17.5s`（镜08–09）：旁人都在躲开白栖，金多贞却反而穿过人群挤过来拉住白栖衣袖（纯韩语急切）：`백서야, 네 이름이 왜 저기 있어? 너 어제 시험 다 봤잖아!`（白栖，你的名字怎么会在那儿？你昨天考试明明全答完了啊！）

   * `17.5–23.0s`（镜10–11）：人群另一侧，南智宥抱着手臂冷笑看着大屏（纯韩语嘲讽）：`특례 입학이라더니, 결국 꼴찌네.`（还以为特招生多厉害，结果还是垫底啊。）都润书站在台阶高处双手插兜饶有兴致看戏。

   * `23.0–28.0s`（镜12）：白栖平静抬头望向大屏红框，随即转身大步朝教务大厅走去。

### 第二段 `03_002`｜认出“副校长室封装”主动追问 + 调取原始扫描件（`29.0s / 13镜`）

1. **认出封装标签，主动追问原始答题卡（`0.0–12.0s` · 镜01–05）**：

   * 教务处复议大厅（`S13-ACADEMIC-HALL`），干事桌角摆着一叠牛皮纸密封袋，上面印着与 EP02 墙牌一致的韩文 **`교감실 봉인`**（后期旁边浮现中文 **`副校长室封装`**）。

   * 白栖目光定在那个封装标签上停了一瞬（认出正是昨晚笔记里查到的负责方），随即抬头语气坚定地主动追问（纯韩语）：`저는 답안지를 잘못 마킹하지 않았습니다. 제 원본 OMR 카드를 확인해 주세요.`（我没有涂错答题卡，请确认我的原始答题卡。）

   * 干事心虚推眼镜敷衍拒绝（纯韩语）：`시스템 자동 채점이라 오류는 없어. 돌아가.`（系统自动阅卷不会出错，回去吧。）

2. **姜书沅依规打开权限（`12.0–20.0s` · 镜06–09）**：

   * 姜书沅（`C02-JIANG`）走进复议大厅，冷眼扫过心虚的干事，按校规开口（纯韩语）：`성적 이의 제기는 학칙상 원본 열람 대상이야. 열어.`（成绩复议按校规有权调阅原件，打开。）

   * 干事不敢违抗，只得敲击键盘调出文件。

3. **扫描件与成绩不符，白栖要求核对修改记录（`20.0–29.0s` · 镜10–13）**：

   * 显示器亮出白栖的**原始涂卡微距扫描件（`P14-SCAN-COMPARE` 左侧）**——客观题涂卡区工整填满，与旁边显示的“0分/漏涂”得分完全不符！

   * 白栖看清扫描件后立刻抓住破绽，主动追问推进查案（纯韩语）：`원본 마킹은 그대로인데 점수만 다릅니다. 수정 기록을 확인해 주세요.`（原始涂卡明明都在，只有分数不对。请核对修改记录。）

   * 玻璃墙外徐易安与都润书眼神微动，干事额头冒汗。

### 第三段 `03_003`｜对照答案控分 C 级 + 23:00 日志实锤 + 白栖独白（`28.0s / 12镜`）

1. **第一步证据：扫描件对照标准答案，原分稳在 C 级（`0.0–11.5s` · 镜01–05）**：

   * 显示器直接调出**预制成绩对照底图（`P14-SCAN-COMPARE`：原始涂卡 + 标准答案 + 复核总分）**——证明客观题与标准答案 100% 吻合全对、主观大题留空，复核总分精准卡在 **C 级中游安全线**！（删去掏草稿纸动作，避免与001放飞纸飞机矛盾。）

   * 姜书沅盯着对照结果，黑眸微微一凛（看穿了她在故意控分藏拙，更确认她不可能垫底）。

2. **第二步证据：23:00 手动改分日志 + 干事吐半句悬念（`11.5–22.0s` · 镜06–09）**：

   * 姜书沅逼近一步点开修改记录，**预制日志底图（`P15-EDIT-LOG`）**清晰显示：**`어젯밤 23:00 / 백서 객관식 점수 0점 수동 수정`**（后期中文花字：**`昨晚 23:00，白栖客观题得分被手动改为 0`**）。

   * 小干事双腿发软慌张脱口（纯韩语）：`죄송합니다… 위에서 시켜서…`（对不起……是上面让我……）

   * 话未说完，旁边赶来的主管立刻黑着脸打断并把干事拉走（纯韩语掩饰）：`단순 입력 실수입니다. 즉시 정정하겠습니다.`（只是单纯录入失误，立刻更正。）

3. **白栖闭口中文内心独白：收在证据够得着的地方（`22.0–28.0s` · 镜10–12）**：

   * 走廊阴影里，白栖看着被拉走的干事和紧闭的副校长室门方向，全程闭口不张嘴。

   * 白栖（纯中文内心独白，冷静压抑）：**`我的分是被人改的。姐，你当年也是这样进去的吗？`**

### 第四段 `03_004`｜白栖撤榜空拍 → 同时刻交叉剪辑银饰手点击 → 金多贞被顶上红名单（`27.0s / 11镜`）
