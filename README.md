# AI 短剧制作知识库

整理小说推文、旁白漫剧和对白短剧的前期工作：故事改编、剧本、人物场景道具、参考图、分镜、视频提示词及交付检查。

提供可复制的中文模板，保留原始提示词供对照，并记录各类外部工具的分工。可以配合 Codex、WorkBuddy 或其他能够读取本地文件的助手使用。

## 使用原则

- 忠实转写与精简改编分开；推断和建议不能冒充原文事实。
- 使用角色、场景、道具和镜头编号追踪连续性，区分真实参考图与待制作计划。
- 按内容决定镜数，以试读和动作需要分配时间。10秒和15秒是规划档位，具体服务能力需在生成前核对。
- 模板默认只产出文字，实际生成媒体另行执行。视频清晰度由用户在生成端控制，提示词不主动填写分辨率或画质档位。

完整规则见 [通用规则](prompts/整理版/01_通用规则.md)。
